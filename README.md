## 1. 安装与配置

### 1.1 Docker 安装使用

#### 前置要求

- **Docker** 20.10 或更高版本
- **Docker Compose** 2.0 或更高版本

#### 安装 Docker

**macOS:**
```bash
# 使用 Homebrew 安装
brew install --cask docker

# 或从官网下载 Docker Desktop
# https://www.docker.com/products/docker-desktop
```

**Linux (Ubuntu/Debian):**
```bash
# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安装 Docker Compose
sudo apt-get update
sudo apt-get install docker-compose-plugin
```

**Windows:**
从 [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop) 下载并安装。

#### 验证安装

```bash
docker --version
docker-compose --version
```

### 1.2 环境变量配置

系统通过环境变量进行配置。您可以通过创建 `.env` 文件来设置这些变量，或直接在 `docker-compose.yml` 中修改默认值。

#### 创建 .env 文件

在项目根目录创建 `.env` 文件：

```bash
touch .env
```

#### 必需配置项

在 `.env` 文件中配置以下变量：

```bash
# ==================== Flask 应用配置 ====================
# Flask 应用入口文件（通常不需要修改）
FLASK_APP=TDRM.py

# Flask 运行环境：development 或 production
FLASK_ENV=production

# Flask 密钥（用于会话加密，生产环境请务必修改为随机字符串）
SECRET_KEY=your-secret-key-change-in-production

# Web 服务端口（默认 5000，macOS 建议改为 5001 避免与 AirPlay 冲突）
WEB_PORT=5001

# ==================== 数据库配置 ====================
# MySQL Root 密码
MYSQL_ROOT_PASSWORD=rootpassword

# MySQL 数据库名称
MYSQL_DATABASE=tdrm

# MySQL 用户名
MYSQL_USER=tdrm_user

# MySQL 用户密码
MYSQL_PASSWORD=tdrm_password

# MySQL 端口（默认 3306）
MYSQL_PORT=3306

# 数据库连接 URL（系统会自动根据上述配置生成，通常无需手动设置）
# DATABASE_URL=mysql+pymysql://tdrm_user:tdrm_password@db:3306/tdrm?charset=utf8mb4

# ==================== 邮件配置（可选）====================
# 邮件服务器地址（如：smtp.gmail.com）
MAIL_SERVER=

# 邮件服务器端口（通常为 587 或 465）
MAIL_PORT=587

# 是否使用 TLS（true/false）
MAIL_USE_TLS=true

# 是否使用 SSL（true/false，与 TLS 二选一）
MAIL_USE_SSL=false

# 邮件用户名（通常是邮箱地址）
MAIL_USERNAME=

# 邮件密码（或应用专用密码）
MAIL_PASSWORD=

# 默认发件人地址
MAIL_DEFAULT_SENDER=
```

#### 配置说明

- **SECRET_KEY**: 用于 Flask 会话加密，生产环境请使用随机生成的字符串。生成方式：
  ```bash
  python -c "import secrets; print(secrets.token_hex(32))"
  ```

- **WEB_PORT**: Web 服务端口。macOS 系统默认 5000 端口可能被 AirPlay 占用，建议设置为 5001 或其他端口。

- **邮件配置**: 如需使用密码重置功能，必须配置邮件服务器。如果不需要此功能，可以留空。

- **数据库配置**: 系统使用 MySQL 8.0，通过 Docker Compose 自动部署。数据库数据会持久化保存在 Docker 卷中。

## 2. 数据库初始化

系统首次启动时会自动创建数据库表结构。如需填充测试数据，请执行以下步骤：

### 2.1 启动服务

```bash
# 启动所有服务（包括数据库和 Web 应用）
docker-compose up -d

# 等待服务完全启动（约 30 秒）
docker-compose ps
```

### 2.2 执行数据库迁移

```bash
# 进入 Web 容器
docker exec -it tdrm_web /bin/bash

# 执行数据库迁移（创建表结构）
flask db upgrade
```

### 2.3 填充种子数据

在容器内执行：

```bash
python seed.py
```

或在宿主机执行：

```bash
docker exec -it tdrm_web python seed.py
```

### 2.4 种子数据说明

`seed.py` 脚本会自动生成以下测试数据：

- **6 栋宿舍楼**: 包括紫荆学生公寓、南区宿舍、文苑等
- **80 名学生用户**: 10 位学号格式（年份 + 院系代码 + 4 位随机数）
- **5 名维修工**: 工号格式为 `2020990001` - `2020990005`
- **7 种维修配件**: LED 灯、插座、水龙头阀芯等常见配件
- **150 条报修单**: 包含不同状态（待处理、已派单、进行中、已完成、已取消）

**注意**: 执行 `seed.py` 会清空现有数据并重新生成。执行完成后，控制台会输出默认账号信息。

## 3. 启动项目

### 3.1 首次启动

```bash
# 1. 进入项目目录
cd /path/to/TDRM

# 2. 构建并启动所有服务（后台运行）
docker-compose up -d --build

# 3. 查看服务状态
docker-compose ps
```

### 3.2 验证启动

等待约 30 秒后，访问以下地址：

- **Web 应用**: http://localhost:5001 （如果修改了 `WEB_PORT`，请使用对应端口）
- **登录页面**: http://localhost:5001/auth/login

### 3.3 查看日志

```bash
# 查看所有服务日志
docker-compose logs -f

# 查看 Web 服务日志
docker logs -f tdrm_web

# 查看数据库服务日志
docker logs -f tdrm_db
```

### 3.4 停止服务

```bash
# 停止所有服务（保留容器和数据）
docker-compose stop

# 停止并删除容器（保留数据卷）
docker-compose down

# 完全重置（删除容器、网络和数据卷）
docker-compose down -v
```

### 3.5 重启服务

```bash
# 重启所有服务
docker-compose restart

# 重新构建并启动
docker-compose up -d --build
```

## 4. 操作指南

### 4.1 通用功能

#### 登录系统

1. 访问登录页面：http://localhost:5001/auth/login
2. 输入账号和密码（参考 [默认账号](#5-默认账号)）
3. 点击"登录"按钮
4. 系统会根据用户角色自动跳转到对应界面：
   - 管理员 → 后台仪表盘
   - 学生 → 学生首页
   - 维修工 → 维修工仪表盘

#### 忘记密码

1. 在登录页面点击"忘记密码？"链接
2. 输入注册时使用的邮箱地址
3. 点击"发送重置邮件"
4. 检查邮箱（需配置邮件服务器，否则无法使用此功能）
5. 点击邮件中的重置链接
6. 设置新密码并确认

**注意**: 如果未配置邮件服务器，请联系管理员重置密码。

#### 修改密码

1. 登录后，点击右上角用户菜单
2. 选择"修改密码"
3. 输入旧密码和新密码
4. 点击"提交"
5. 系统会自动退出登录，请使用新密码重新登录

#### 退出登录

点击右上角用户菜单，选择"退出登录"。

### 4.2 学生用户

#### 发起报修

1. 登录后进入学生首页
2. 点击左侧菜单"新建报修"或首页的"创建报修单"按钮
3. 填写报修信息：
   - **报修标题**: 简要描述问题（如"灯不亮了"）
   - **详细描述**: 详细说明问题情况
   - **报修位置**: 系统自动填充宿舍号，可手动修改
   - **上传图片**: 点击"选择文件"上传问题照片（支持 JPG、PNG、GIF，最大 16MB）
4. 点击"提交报修单"
5. 系统会生成报修单号，状态为"待处理"

#### 查看报修进度

1. 点击左侧菜单"我的报修"
2. 查看报修单列表，包括：
   - 报修单号
   - 标题和描述
   - 提交时间
   - 当前状态（待处理、已派单、进行中、已完成、已取消）
   - 分配的维修工（如有）
3. 点击报修单号或"查看详情"查看完整信息

#### 确认完工并评价

1. 当报修单状态为"已完成"时，进入报修单详情页
2. 点击"确认完工"或"评价"按钮
3. 填写评价：
   - **评分**: 选择 1-5 星（5 星为最高）
   - **反馈意见**: 可选，填写对维修服务的评价
4. 点击"提交评价"
5. 评价提交后，报修单流程结束

---

### 4.3 维修工用户

#### 查看任务列表

1. 登录后进入维修工仪表盘
2. 点击左侧菜单"我的任务"
3. 查看分配给您的工单：
   - **待处理**: 管理员已派单，等待开始维修
   - **进行中**: 已开始维修的工单
   - **已完成**: 已完成的工单

#### 接单/开始维修

1. 在"我的任务"页面，找到状态为"待处理"的工单
2. 点击工单详情，查看报修信息、位置和图片
3. 点击"开始维修"按钮
4. 工单状态变为"进行中"

#### 维修填报（录入耗材和工时）

1. 在"进行中"的工单详情页，点击"完成维修"或"填报"
2. 填写维修记录：
   - **开始时间**: 系统自动填充，可手动修改
   - **结束时间**: 维修完成时间
   - **维修结果**: 描述维修过程和结果
   - **工时费用**: 维修所用工时对应的费用（系统按 50 元/小时计算）
   - **使用配件**: 
     - 点击"添加配件"
     - 选择配件名称
     - 输入使用数量
     - 系统自动计算配件费用并更新库存
3. 点击"提交维修记录"
4. 工单状态自动变为"已完成"，等待学生确认

#### 查看历史记录

1. 点击左侧菜单"历史记录"
2. 查看所有已完成的工单
3. 可按日期范围筛选
4. 查看工单详情、维修记录和学生评价

---

### 4.4 管理员用户

#### 进入后台仪表盘

1. 使用管理员账号登录
2. 系统自动跳转到后台仪表盘（`/admin/index`）
3. 仪表盘显示关键指标：
   - 待处理工单数量
   - 库存预警数量
   - 本月已完工数量
   - 总用户数
   - 近 7 日维修趋势图表
   - 工单状态分布
   - Top 5 报修楼宇
   - 配件消耗统计

#### 派单流程

1. 点击左侧菜单"工单管理"
2. 在工单列表中，找到状态为"待处理"（Pending）的工单
3. 点击工单详情，查看报修信息、位置和图片
4. 点击"派单"或"指派维修工"按钮
5. 在派单表单中：
   - 选择维修工（从下拉列表中选择）
   - 可添加备注说明
6. 点击"确认派单"
7. 工单状态变为"已派单"（Assigned），维修工可在"我的任务"中查看

#### 库存管理

##### 查看库存列表

1. 点击左侧菜单"库存管理"
2. 查看所有配件的库存信息：
   - 配件名称和规格
   - 当前库存数量
   - 预警线（库存低于此值会显示预警）
   - 单价
   - 单位

##### 添加配件库存

1. 在库存管理页面，找到需要补充的配件
2. 点击"编辑"按钮
3. 修改"当前库存"数量
4. 点击"保存"
5. 库存更新后，如果库存高于预警线，预警提示会自动消失

##### 添加新配件

1. 点击左侧菜单"库存管理"
2. 点击"添加配件"或"新建"按钮
3. 填写配件信息：
   - 配件名称
   - 规格型号
   - 单位（如：个、套、米）
   - 单价
   - 当前库存
   - 预警线（建议设置为 10）
4. 点击"提交"或"保存"

#### 其他管理功能

##### 人员管理

1. 点击左侧菜单"人员管理"
2. 查看所有用户列表（学生、维修工、管理员）
3. 可以：
   - 查看用户详细信息
   - 编辑用户信息
   - 禁用/启用用户账户

##### 楼宇管理

1. 点击左侧菜单"楼宇管理"
2. 查看所有宿舍楼信息
3. 可以：
   - 添加新楼宇
   - 编辑楼宇信息（名称、位置、联系方式）
   - 删除楼宇（需确保无关联工单）

##### 工单管理

1. 点击左侧菜单"工单管理"
2. 查看所有工单（支持筛选和搜索）
3. 可以：
   - 按状态筛选（活跃工单/历史工单）
   - 搜索工单（按标题、工单号、学生姓名、楼宇）
   - 查看工单详情
   - 派单给维修工
   - 查看维修记录和评价

## 5. 默认账号

执行 `seed.py` 脚本后，系统会创建以下测试账号：

### 管理员账号

| 账号 | 密码 | 说明 |
|------|------|------|
| `2010000000` | `admin123` | 系统管理员，拥有所有权限 |

### 维修工账号

| 账号 | 密码 | 说明 |
|------|------|------|
| `2020990001` | `123456` | 张师傅 |
| `2020990002` | `123456` | 王师傅 |
| `2020990003` | `123456` | 李师傅 |
| `2020990004` | `123456` | 赵工 |
| `2020990005` | `123456` | 刘工 |

### 学生账号

学生账号为随机生成的 10 位学号，格式为：`年份 + 院系代码(01) + 4位随机数`

例如：`2025011234`、`2023015678`

**所有学生账号的默认密码均为**: `123456`

#### 查看学生账号

执行 `seed.py` 后，控制台会输出示例学生账号。您也可以通过以下方式查看：

**方式一：通过数据库查询**
```bash
# 进入数据库容器
docker exec -it tdrm_db mysql -u tdrm_user -ptdrm_password tdrm

# 查询学生账号
SELECT account, username, email FROM sys_user WHERE role = 'student' LIMIT 10;
```

**方式二：通过管理员后台**
1. 使用管理员账号登录
2. 进入"人员管理"
3. 筛选角色为"学生"
4. 查看学生账号列表
